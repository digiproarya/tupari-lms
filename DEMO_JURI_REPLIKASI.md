# Skenario Demo Juri — Replikasi TuPARI EDU

**Durasi target: 3–4 menit.** Demo harus menggunakan akun Google uji dan data dummy.

1. Tampilkan portal TuPARI dan tombol **Buat LMS Saya**.
2. Jelaskan: frontend bisa terpusat, tetapi backend/database sekolah dibuat pada akun Google pemilik sekolah.
3. Tampilkan project Apps Script paket installer (hindari membaca kode panjang).
4. Jalankan installer pada akun uji, isi sekolah dan administrator dummy.
5. Tampilkan spreadsheet dan folder Drive yang baru dibuat di akun tersebut.
6. Jalankan diagnosis; tunjukkan status aset.
7. Deploy Web App dan salin URL.
8. Buka frontend, masukkan/passing URL backend; tes koneksi.
9. Login dengan akun administrator dummy.
10. Tutup dengan pesan: **Satu platform, setiap sekolah memiliki data dan backend sendiri.**

## Jangan klaim
- Instalasi satu klik/otomatis penuh belum tersedia.
- Belum diuji end-to-end pada akun baru.
- Belum aman untuk data siswa nyata.
